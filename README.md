# Neovim configuration

Simple neovim configuration.

Included plugins:
*   **Autopairs**: [windwp/nvim-autopairs](https://github.com/windwp/nvim-autopairs)
*   **Catppuccin**: [catppuccin/nvim](https://github.com/catppuccin/nvim)
*   **Comment**: [numToStr/Comment.nvim](https://github.com/numToStr/Comment.nvim)
*   **Gitsigns**: [lewis6991/gitsigns.nvim](https://github.com/lewis6991/gitsigns.nvim)
*   **Highlight colors**: [brenoprata10/nvim-highlight-colors](https://github.com/brenoprata10/nvim-highlight-colors)
*   **Lualine**: [nvim-lualine/lualine.nvim](https://github.com/nvim-lualine/lualine.nvim)
*   **nvim-lspconfig**: [neovim/nvim-lspconfig](https://github.com/neovim/nvim-lspconfig)
*   **Surround**: [kylechui/nvim-surround](https://github.com/kylechui/nvim-surround)
*   **Telescope**: [nvim-telescope/telescope.nvim](https://github.com/nvim-telescope/telescope.nvim)
*   **Treesitter**: [nvim-treesitter/nvim-treesitter](https://github.com/nvim-treesitter/nvim-treesitter)
*   **Which Key**: [folke/which-key.nvim](https://github.com/folke/which-key.nvim)
*   **Zen Mode**: [folke/zen-mode.nvim](https://github.com/folke/zen-mode.nvim)
